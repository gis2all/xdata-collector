# Roadmap

## Near Term

- Keep the local desktop API contract stable while route handling moves toward a framework or a stricter routing layer.
- Expand browser E2E coverage for manual runs, scheduled jobs, result filtering, and logs.
- Publish release notes for each tagged version and keep Docker smoke checks green.

## Later

- Add richer OpenAPI schemas for request and response bodies.
- Split large page containers into smaller state and view modules as workflows settle.
- Add query-plan level tests for larger result sets and advanced filters.
